CRAVE CLUB — Café Playground

FILES
- index.html: app structure
- style.css: all visual styling and responsive layouts
- app.js: menu, orders, tables, stock, contacts and localStorage
- favicon.svg: original CC-inspired browser icon

RUN
1. Extract the ZIP.
2. Open the crave-club folder in VS Code.
3. Double-click index.html, or right-click it and choose Open with your browser.
   Live Server is not required for core features.

IMPORTANT STORAGE NOTES
- Data is stored in localStorage for the current browser profile/device.
- Direct-file browser storage may be isolated by browser and file URL. It does not sync across devices.
- localStorage is not encryption. Anyone with access to the unlocked device/browser profile may be able to inspect records.
- Clearing browser data may erase records.
- Food images are resized/compressed in the browser before saving. Browser storage is limited; if saving fails, try a smaller image.
- Orders snapshot names, prices and quantities at the time of order. Stock is managed manually and does not automatically decrease.

No backend, analytics, ads, paid services, frameworks or build system are used.
Google Fonts are optional; system fallback fonts keep the interface styled offline.
